# Dated Korean legal-size evidence overlay

This sibling does not modify the base benefit atlas or recruitment directory. `labels` refer only to accepted base `KR-CRN` or directory `KR-BIZ` IDs; `ftc_only` is a distinct set of FTC legal-registration identities, not recruitment employers. An absent label means **unclassified**, not small/medium. No record establishes a current benefit policy or approved benefit.

`large_affiliate` means **공시대상기업집단 소속(2026-11-02)**, an affiliation on the FTC reference date, not standalone assets. FTC source: 공정거래위원회, [2026년 11월 공시대상기업집단 소속회사 현황](https://www.ftc.go.kr/www/selectBbsNttView.do?bordCd=3&key=12&nttSn=48244), 공공누리 제1유형 (출처표시). `mid_history` means historical mid-sized certificate-based fund participation **as of 2026-06-30**, without a supplied certificate expiry; it must not be displayed as a verified current classification. `sme_unspecified` means a dated talent-development SME designation still valid at the 2026-11-20 evaluation date; it does not prove the small/medium leaf. All records preserve source keys and reference dates, with an expiry only where supplied.

Rebuild from the five SHA-pinned private source editions with `python3 scripts/generate-domestic-size-evidence.py --ftc <restricted FTC XLSX> --dart <restricted DART XLSX> --mid <restricted fund CSV> --sme <restricted SME CSV>`, then repeat with `--check`. The recruitment CSV is pinned by the frozen directory manifest rather than read again. Private source files, executive names, job titles, addresses and DART rows do not belong in this directory. Rebuild before any client adoption; an overlay is not a benefit approval.

The pinned run emits 402 accepted labels: 270 base CRNs plus 132 directory BIDs (53 FTC affiliate, 4 historical mid-sized, 75 SME-unspecified). A further 3,143 nonoverlapping FTC-only legal CRNs are distinct records. The FTC sheet has 3,529 rows / 3,513 unique CRNs; 16 contradictory group/name CRNs are quarantined. These are source-dated classifications, not current-employer or benefit counts.
