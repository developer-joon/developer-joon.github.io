# 커뮤니티 홈 간소화 디자인

## 목표

커뮤니티 홈을 소개용 랜딩 페이지가 아니라 자유게시판 목록으로 보이게 한다. 모바일 첫 화면에서 설명 문구가 검색과 게시글 목록을 밀어내지 않도록 한다.

## 화면 구성

- 전역 헤더와 커뮤니티 작업 행은 유지한다.
- 본문 첫 영역에는 `자유게시판` H1만 표시한다.
- 다음 요소는 제거한다.
  - `COMMUNITY · 공개 개발 기록` 키커
  - `개발자가 쓰고 답하는 공간` 문구
  - 게시판 성격을 설명하는 본문
  - 상단 작업 행과 중복되는 본문 `글쓰기` 버튼
- 검색, 태그 필터, 오류·재시도, 정렬, 게시글 목록은 기존 동작을 유지한다.
- 축소된 제목 영역에 맞춰 모바일과 데스크톱 상하 여백을 줄인다.

## 접근성과 동작

- `자유게시판`을 페이지의 유일한 H1로 유지한다.
- 글쓰기는 전역 헤더 아래 커뮤니티 작업 행에서 계속 접근할 수 있다.
- 검색·태그·정렬의 접근 가능한 이름과 키보드 동작은 변경하지 않는다.

## 검증

- 컴포넌트 테스트에서 `자유게시판` H1을 확인한다.
- 제거 대상 문구와 본문 중복 `글쓰기` 링크가 DOM에 없음을 확인한다.
- 전체 앱 테스트, 타입 검사, 린트, 프로덕션 빌드와 정적 사이트 검증을 실행한다.
- 운영 배포 후 모바일 DOM에서 간소화된 제목과 태그 목록을 확인한다.

## 같은 배포에 포함할 기존 수정

운영 태그 ID는 PostgreSQL이 허용하는 canonical UUID 문자열이지만 RFC 버전·variant 비트가 없는 고정 ID다. 클라이언트가 이를 잘못 거부하던 문제를 canonical UUID 문법 검증으로 바로잡은 커밋 `591b60a`도 함께 배포한다. API 권한이나 데이터베이스 값은 변경하지 않는다.
