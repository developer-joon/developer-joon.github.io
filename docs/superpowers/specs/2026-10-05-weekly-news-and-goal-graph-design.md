# 최근 일주일 뉴스 5편과 100억 목표 그래프 복원 설계

## 목표

1. 2026년 9월 29일부터 10월 5일까지 발표된 주요 기술 뉴스를 기반으로 기존 147편 및 현재 작성 중인 10편과 겹치지 않는 포스팅 5편을 완성한다.
2. 수익실험실에서 트레이딩 중단과 장기 목표를 분리하고, 기존 100억 원 목표 그래프를 오해 없이 복원한다.

커밋, push, PR, 배포는 수행하지 않는다.

## 최근 일주일 포스팅

- 공식 발표일이 2026-09-29~2026-10-05인 1차 출처를 우선한다.
- 후보마다 기존 147편과 현재 작성 중인 10편의 title, description, tags, H2/H3를 비교한다.
- 같은 제품을 다루더라도 핵심 질문과 결론이 같으면 중복으로 보고 제외한다.
- 정확한 후보 5개는 조사 후 source map에 확정한다.
- 각 글은 4,000~7,000자 내외, 기존 Jekyll front matter, seeded Picsum, 번호 인용과 `## Sources`를 갖춘다.
- 공급자 발표와 운영 해석, preview/beta/GA 상태, 공급자 측정치와 독립 사실을 구분한다.

## 100억 목표 그래프

Git 기록에서 기존 목표 UI가 2026-09-25 상태 현행화 커밋 `f136e8b`에서 제거된 것을 확인했다. 제거 이유는 트레이딩 종료 후 과거 자산을 현재 자산처럼 보여 주지 않기 위해서였으며, 장기 목표 자체의 취소를 뜻하지 않았다.

복원안은 다음과 같다.

- 상태 대시보드 상단에 별도 `장기 목표` 카드를 추가한다.
- 목표 금액은 `₩10,000,000,000`으로 표시한다.
- 목표 상태는 `유효 · 수익모델 전환 중`으로 표시한다.
- 진척 기준은 현재 자산이 아니라 `마지막 공개 스냅샷`임을 카드 안에서 명시한다.
- 마지막 공개 스냅샷은 2026-05-24의 `₩3,085,757`이며 최종 정산값이나 현재 자산이 아니라고 표시한다.
- 참고 진척도는 계산값 `0.0308575700%`를 화면에서 `0.03%`로 표시한다.
- 기존 progress bar의 시각 구조는 복원하되 최소 4px marker를 사용해 매우 작은 진척도가 보이게 한다.
- 트레이딩 상태 `종료·보류`, 포지션 `정리 완료`, 다음 수익모델 `연구 중`은 그대로 유지한다.
- 과거 공개 스냅샷 표와 의미가 충돌하지 않도록 동일한 기준일·금액·주의 문구를 사용한다.

## 검증

- 최근 일주일 5편과 기존/신규 글의 제목·검색 의도·결론 중복을 검사한다.
- 모든 source-bearing 문장을 공식 원문과 대조한다.
- 수익실험실 원본과 생성 HTML에서 목표, 상태, 스냅샷 문구가 모두 존재하는지 검사한다.
- `₩3,085,757`이 현재 자산이나 최종 정산으로 표현되지 않는지 검사한다.
- Docker 정적 사이트 빌드와 artifact verifier를 마지막 편집 후 실행한다.
- 커밋·push·PR·배포가 없음을 작업 트리로 확인한다.
