# Community 검토용 초안

## 메타데이터

- 제목: `복지보다 오래 남는 조직문화는 무엇이었나요?`
- 활성 태그: `자유 이야기` (`free-talk`)
- 게시 상태: `검토 대기·미게시`
- 용도: 내부 검토용 아티팩트이며 Community 게시물이 아님

## 제목 원문

복지보다 오래 남는 조직문화는 무엇이었나요?

## 본문 원문

좋은 복지를 소개하는 글은 많지만, 실제로 오래 기억에 남는 것은 일하는 방식일 때도 있는 것 같습니다.

예를 들면 휴가를 눈치 보지 않고 쓰는 분위기, 회의에서 직급과 관계없이 반대 의견을 말할 수 있는 환경, 업무 시간 밖의 연락을 당연하게 여기지 않는 관행처럼 제도표에는 잘 드러나지 않는 요소들입니다. 반대로 눈에 띄는 복지 제도가 있어도 이용하기 어렵거나, 팀마다 적용 방식이 달라 체감이 작을 수도 있고요.

여러분은 어떤 조직문화가 복지 제도보다 일상의 만족도나 신뢰에 더 큰 영향을 준다고 느꼈나요? 특정 회사를 평가하기보다, 다른 조직에서도 참고할 수 있는 행동이나 운영 방식 중심으로 나눠 주세요. 예를 들면 다음과 같은 경험이 궁금합니다.

- 리더가 말보다 행동으로 보여 준 원칙
- 휴가·회의·피드백처럼 반복되는 과정에서 신뢰를 만든 방식
- 구성원이 부담 없이 의견을 내거나 실수를 공유할 수 있게 한 장치
- 문서에 적힌 제도와 실제 이용 경험의 차이를 줄인 방법
- 규모나 업종이 달라도 적용해 볼 만한 작은 관행

공유할 때는 회사명, 부서, 지역, 정확한 보상 수준, 개인의 건강·가족 정보, 당사자를 알아볼 수 있는 갈등 사례는 빼 주세요. 현재 진행 중인 분쟁의 판단이나 법률·인사 조언을 구하기보다, 익명화한 경험과 일반화할 수 있는 배움을 중심으로 이야기해 보면 좋겠습니다.

## 운영·개인정보 검토 체크리스트

- [ ] 제목이 2자 이상 120자 이하인지 확인
- [ ] 본문이 1자 이상 50,000자 이하인지 확인
- [ ] 활성 태그 `자유 이야기` (`free-talk`) 1개만 지정했는지 확인
- [ ] 회사명·부서·지역 등 고용주나 조직을 특정할 단서가 없는지 확인
- [ ] 정확한 급여·보상액 등 민감한 보상 정보가 없는지 확인
- [ ] 건강·가족사 등 민감정보가 없는지 확인
- [ ] 당사자를 알아볼 수 있는 분쟁·징계·평가 사례가 없는지 확인
- [ ] 법률 또는 인사 판단을 대신하는 조언이 없는지 확인
- [ ] 특정 조직이나 개인을 비난·폭로하도록 유도하지 않는지 확인
- [ ] 댓글에서도 재식별 정보와 비방이 확산되지 않도록 운영 기준을 적용할지 확인
- [ ] Community API·Supabase에 게시하지 않고 `검토 대기·미게시` 상태를 유지했는지 확인
